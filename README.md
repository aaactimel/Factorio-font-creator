## Project Overview

**Factorio rich text generator** is a lightweight front-end utility that outputs Factorio rich text strings like:
```text
[color=#62a0ea][font=default-game]Hello world![/font][/color]
```
Site meant for people who often create stations or blueprints and wants to make them ✨ ***FANCY*** ✨

## Features
Same as [upstream repository](https://github.com/FCTostin-team/fonts-online_rich_text/tree/main/#Features)!
- Visual **font picker** with previews for available Factorio fonts.
- **Real-time rich text generation**.
- **HEX color picker**.
- Live output preview where text color updates instantly.
- **Character-length validator** (with limit feedback for constrained in-game fields).
- **Multi-language UI**.
